# 角色策略、可解释 AI 与对局节奏设计

## 范围

仅覆盖标准六人局和现有狼人、预言家、女巫、平民四种身份。不新增角色、模式或多人房。

## 角色策略卡

服务端为每个角色提供可版本化的策略卡，包含阵营目标、夜间行动原则、公开发言风格、投票原则和禁止泄露的私密事实。策略卡与当前观察数据一起进入模型提示词：狼人侧重协作、伪装和误导；预言家侧重查验与信息何时公开；女巫根据局势、药剂与被袭击者判断救援或毒杀；平民侧重公开发言与票型推理。

策略卡是提示词层，不绕过 `legal_kinds`、合法目标和服务端结算。现有“女巫始终救人”临时强制规则移除，让女巫策略真正由模型决定；模型失败仍安全降级为无动作。

## 可解释性与权限

模型结构化返回 `public_reason`，用于说明公开发言或投票的简短理由。公开行动的理由以公共事件展示；夜间行动理由以仅执行者可见的私密事件保存；狼人同伴建议继续仅狼队可见。终局和死亡全局视角可复盘全部游戏事件，但永不暴露原始 Prompt、模型原始输出、思维链、密钥、成本和诊断信息。

## 对局节奏 UI

浏览器根据服务端事件渲染明确的阶段叙事和行动完成反馈：进入夜晚/白天、角色行动等待、夜间结算、讨论结束、投票统计和放逐结果。只渲染事件中明确存在的公开或已授权私密信息；不会用客户端倒计时或推测性状态替代服务端状态。

## 验收标准

1. 四个角色均有独立策略提示；女巫不再被固定为必救。
2. AI 投票和公开发言可输出经过长度/授权校验的简短理由；非法理由不阻塞对局。
3. 公共理由、私密夜间理由和死亡/终局复盘遵循既有投影权限。
4. 时间线和侧栏显示中文阶段与完成反馈，且不泄露未授权信息。
5. 后端规则、AI 策略、投影 API 与前端组件均有回归测试。
