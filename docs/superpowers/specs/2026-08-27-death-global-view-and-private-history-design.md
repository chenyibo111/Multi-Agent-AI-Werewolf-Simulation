# 死亡全局视角与角色私密档案设计

## 目标

让存活玩家只能查看自己的角色私密信息；玩家死亡后立即转为安全的全局观战视角，能够查看全部角色身份、全部游戏私密事件和所有夜间结算细节。任何模型或服务端内部数据始终不对浏览器开放。

## 权限边界

存活人类继续使用现有的最小权限投影：其他角色身份、其他玩家私有事件和服务器事件都不可见。死亡玩家不再使用普通旁观投影，而是使用全局游戏投影；该投影包含所有角色、所有游戏级私密事件和公共事件。

全局游戏投影不包含 `Visibility.SERVER` 事件，且无论视图类型如何都递归剔除以下内部字段：`raw_prompt`、`raw_model_response`、`secret`、`api_key`、`chain_of_thought`。模型调用用量、预算、服务端诊断和会话凭据均不进入此投影。

## 私密行动记录

夜间结算将为拥有该能力的角色写入明确的私密事件，而不是只在临时行动表单中提供信息：

- 女巫在进入行动阶段时收到“今晚被袭击者”的私密信息；结算时收到自己的救人目标、毒杀目标及是否救援成功。
- 预言家继续获得私密查验结果，包含目标和是否为狼人。
- 狼人继续获得仅狼队可见的同伴建议；全局视角可查看该建议，因为它属于游戏事件而非系统内部数据。

玩家自己的私密事件在存活期间持续保留并可回看。死亡后全局视角包含这些事件以及所有其他玩家的私密事件。

## API 与界面

后端根据 `ViewerKind` 构造三种明确投影：存活私密视图、死亡全局视图、结束复盘视图。死亡和结束视图均使用同一套安全事件过滤规则，不再依赖前端推断或拼接隐藏数据。

前端为私密事件补齐可读叙事：展示女巫看见的被袭击者、救人/毒人结果和药剂状态；存活角色仅显示授权事件。死亡时保留时间线，显示所有角色身份与夜间私密行动；不展示原始 JSON 或未识别载荷。

## 验收标准

1. 活着的非相关角色仍看不到他人的身份和私密事件。
2. 人类女巫能在行动时看到被袭击者，并在后续私密记录中回看救人/毒人结果与药剂消耗。
3. 人类预言家能回看全部自己的查验结果；人类狼人能回看同伴建议。
4. 人类死亡后，接口立即返回所有角色身份以及全部公共和游戏私密事件；前端以安全文本展示它们。
5. 死亡全局视图和结束复盘都不会返回服务器事件、模型原始提示词/输出、密钥、成本或诊断数据。
6. 后端测试、静态检查、前端测试与类型检查均通过。
